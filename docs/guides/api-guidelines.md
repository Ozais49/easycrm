# API Guidelines

> Purpose: REST conventions. Status: Draft — **REST + OpenAPI confirmed**

## Routes
- `/api/{module-resource}` plural kebab-case: `/api/contacts`, `/api/deals/{id}/stage`
- Actions that aren't CRUD: `POST /api/leads/{id}/convert`
- Webhooks: `/webhooks/{provider}`
- Share links: `/share/{token}` (watermarked media only)
- **Public Content API**: `/public/v1/{portfolio|calendar/events|availability|updates}` — read-only and published/public items only, authenticated with a per-tenant API key (`X-Api-Key`), rate-limited, edge-cached on Cloudflare (`Cache-Control` + purge on publish) — [ADR-0011](../adr/0011-public-content-api-and-watermarking.md)

## Methods & status codes
- GET 200, POST 201 (+ Location), PUT/PATCH 200 or 204, DELETE 204
- 400 validation, 401 unauthenticated, 403 forbidden, 404 not found (also for other-tenant records), 409 conflict

## Lists
- `?page=1&pageSize=25&sort=-createdAt&q=search&filter[status]=open`
- Response: `{ items, page, pageSize, total }`

## Errors
- RFC 7807 ProblemDetails; validation errors in `errors: { field: [messages] }`

## Concurrency
- `ETag` / `If-Match` or row version on updates — TODO decide

## Sensitive fields
- Omitted from responses when not permitted (absent, not null)

## Versioning & docs
- OpenAPI document generated by the host (built-in `Microsoft.AspNetCore.OpenApi`, `/openapi/v1.json`, Development only); versioning TODO (none until needed)
- The web client is generated from this document (orval, snapshot in `web/openapi/cem.json`). Every endpoint therefore declares a unique PascalCase `.WithName("...")` and its responses (`.Produces<T>()`, `.ProducesProblem(...)`, `.ProducesValidationProblem()`); `/api` has 401 and 403 declared once on the group. Webhooks are `.ExcludeFromDescription()`.
